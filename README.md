# Calculator

## Overview
This is a simple and user-friendly calculator web application that performs basic arithmetic operations. It is built using HTML, CSS, and JavaScript to provide a responsive and interactive experience.

## Features
- Perform basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- User-friendly interface with a clean design.
- Responsive layout for different screen sizes.
- Clear button to reset calculations.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript

## Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/calculator.git
   cd calculator
   ```

2. **Run the application:**
   - Open the `index.html` file in any web browser.

## Usage
1. Enter numbers using the on-screen buttons.
2. Click on the arithmetic operators to perform calculations.
3. Press `=` to get the result.
4. Use `C` or `Clear` to reset the input.
